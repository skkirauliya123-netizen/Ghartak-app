# GharTak (घरतक) - Gaon Ki Apni Dukan

GharTak is a mobile-responsive local delivery and grocery web app designed specifically for rural communities to bridge the gap between local vendors and households.

## Features
- 🛒 **Local Catalog:** Daily sabzi, dairy, and grocery items with real-time pricing.
- 📱 **PWA Support:** Instantly installable on mobile home screens without heavy APK downloads.
- ⚡ **Lightweight & Fast:** Built with pure HTML/CSS/JavaScript running on Netlify.
- 📍 **SEO Optimized:** Integrated with Google Search Console for local discovery.
